### DOCUMIND AI
DocuMind AI is an end-to-end intelligent document processing system designed to transform unstructured documents into meaningful, searchable, and actionable insights using modern AI techniques.
## Problem Statement:
Organizations generate massive volumes of unstructured documents, making manual processing slow, error-prone, and inefficient.  
There is a need for an intelligent system that can automatically extract, summarize, and organize information for faster and more accurate decision-making.

## Tech Stack

* **Frontend:** HTML,React.js(Vite)
* **Backend:** Python (FastAPI)
* **AI Engine:** OpenAI (GEMINI-FLASH-LATEST)
* **Orchestration:** LangChain
* **Vector Database:** Pinecone,FAISS
* **File Processing**	Pdfplumber

## Features Implemented
* Built a Streamlit web application for automated document classification and real-time processing.
* Extracted text from images and PDFs using Tesseract OCR and OpenCV.
* Trained a custom NLP model using PyTorch and Hugging Face Transformers for precise information
extraction and confidence scoring.
* Tracked machine learning experiments and managed datasets using MLflow.
